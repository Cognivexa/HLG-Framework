# Spreadsheet Insights

Every insight ships with its calculation attached, so nobody has to trust a number blindly.

## Input

$ARGUMENTS

## How It Works

1. Profile the data for missing values, outliers, and type mismatches
2. Identify the two or three questions the data can actually answer
3. Compute each insight and show the underlying formula or query
4. Flag any insight that depends on a small or biased sample
5. Summarize findings in plain language before the supporting tables
