# YouTube Script Planner

Plan videos around retention curves, not just a topic outline.

## Input

$ARGUMENTS

## How It Works

1. Define the single promise the video makes in the first 15 seconds
2. Break the script into beats with a hook every 30-45 seconds
3. Timestamp each beat so pacing can be reviewed before filming
4. Place the CTA where retention data suggests, not just at the end
5. Draft a thumbnail-and-title pair aligned with the hook
