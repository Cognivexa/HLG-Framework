# Executive Briefing Digest

One page, decision first, everything else in an appendix.

## Input

$ARGUMENTS

## How It Works

1. Read the full source document before summarizing anything
2. State the decision or ask in the first sentence
3. Summarize supporting context in three bullets or fewer
4. Move detail and caveats into an appendix, not the main brief
5. Flag any risk that could change the recommendation
