# PRD Template Builder

Turn a rough feature request into a spec engineering can actually estimate against.

## Input

$ARGUMENTS

## How It Works

1. Separate the stated problem from any solution already baked into the request
2. Draft explicit scope and non-goals to prevent creep
3. Define a measurable success metric, not an aspirational one
4. List edge cases and cross-team dependencies
5. Flag open questions that block estimation instead of guessing at answers
