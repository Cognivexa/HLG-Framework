# File Organizer Pro

Understand what files actually are before moving them, not just their extensions.

## Input

$ARGUMENTS

## How It Works

1. Scan the target directory and classify files by content and context
2. Detect likely duplicates and near-duplicates
3. Propose a folder structure grouped by project or purpose
4. Ask for confirmation before any move, rename, or delete
5. Log every change made so it can be reversed
