# Tapestry

Weaves a pile of scattered links and notes into one action plan, instead of leaving them as separate tabs nobody revisits.

## Input

$ARGUMENTS

## How It Works

1. Collect all supplied notes, articles, and links related to the topic.
2. Extract the key claims and recommendations from each source.
3. Identify overlaps, contradictions, and gaps across the collected material.
4. Group related points into themes and resolve conflicting advice with explicit reasoning.
5. Produce a single ordered action plan that reflects the synthesized findings.
